# 用户手册

## 1. 页面概览

### 顶栏 Hero

| 列 | 含义 |
|----|------|
| **账户资产** | 各基金已入账 `amount` 之和 |
| **预估**（副标题） | live：`账户资产 + 实时收益`；snap（16:00–21:30 / 04:00–08:00）：**`B[D] + RT1` 冻结**（入账后账户资产变、预估可不变） |
| **实时收益** | 穿透 row1，盘前/盘后不含 row2 |
| **当日收益** | 官方净值公布后入账的盈亏 |
| **持有收益** | 累计盈亏 |

### 状态条

`盘中 · 美股` / `盘前 · 美股` / `盘中 · 亚太` / `休市` 等，表示当前有报价的 **交易所** 及其时段（非单基金类型）。多市场若处于不同段（如亚太正盘），chip 按段分组展示。黄金联接跟 A 股，不单独显示黄金。无美股夜盘时段。

### 底部导航

| Tab | 说明 |
|-----|------|
| **持仓** | 账户概况 / 全部持仓 / 单渠道列表 |
| **收益** | 官方入账收益日历（非 RT1） |
| **自选** | 关注基金列表 |
| **我的** | 主题、API、Mac 局域网地址等 |

### 顶栏账户 Tab（持仓页内）

| Tab | 说明 |
|-----|------|
| **账户概况** | 各渠道卡片汇总 |
| **全部持仓** | 同代码跨账户 merge |
| **支付宝** 等 | 单渠道未 merge 视图 |

**当日收益 pending**：16:00 起若净值未入账显示 `—`（见 [realtime-spec.md](./realtime-spec.md) 规则 3b）。

## 2. 收益列说明

### 实时收益

- **有行情**：金额 + 涨跌幅；美股 QDII 在盘前/盘后可能为 **双行**（正盘一行 + 盘前/盘后一行）
- **无行情**：`—`（例如 A 股已收市且处于美股正盘时段）
- **收市后（A 股日盘结束、美股未开）**：可显示当日最后一次穿透/估值（snapshot）

### 当日收益

- 来源：东财公布净值入账
- **待更新**：净值日晚于期望日时显示 `—`
- A 股/黄金联接通常对应当天；QDII 可能滞后 1 个 US 交易日

### 持有收益

截至各基金**已入账净值日**的累计盈亏。

## 3. 预估资产怎么理解

```
live 阶段：预估 ≈ 账户资产 + 实时收益（Σ amount + Σ ep）
snap 阶段：预估 ≈ B[D] + RT1（日初 baseline + 冻结 RT1，见 realtime-spec §2.1）
```

- live 表示在**当前已入账 amount** 上叠加穿透 row1
- snap 阶段（16:00–21:30、04:00–08:00）：**账户资产可随净值入账变大，预估保持不变**

## 4. 隐私与主题

- 点击账户资产旁 **眼睛图标**：隐藏金额，保留涨跌幅
- 右上角切换 **深色 / 浅色** 主题

## 5. 管理持仓

在单渠道 Tab 下可：

- 调整基金顺序（⚙ 列表配置）
- 添加 / 编辑 / 删除基金（需在该渠道 Tab 内）

## 6. 自动入账

服务端约每 1 分钟检测净值是否更新；若 `navDate > lastNavDate`，自动：

- 更新份额、`amount`、当日收益、持有收益

无需手动操作；也可调用 `POST /api/settle/run` 触发。

## 7. 常见问题

**Q：为什么支付宝里有的基金晚上 22 点实时是 `—`？**  
A：A 股/黄金联接跟 A 股时间。美股正盘（约 21:30–04:00）且 A 股已收市时， intentionally 不显示 A 股收盘估值。

**Q：盘前为什么 header 实时不变、列表第二行在变？**  
A：盘前增量只在 row2；header 与 row1 在 16:00 snap 后冻结。

**Q：预估和「账户资产 + 实时心算」不一致？**  
A：请硬刷新页面。若仍异常，运行 `npm run verify:alipay-realtime` 排查。

**Q：重启电脑后数字变了？**  
A：检查 `data/day-display-state.json` 是否存在且可写；生产需持久化挂载 `data/`。
