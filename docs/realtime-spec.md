# 实时收益功能规格

> 基准场景：**北京时间 2026-05-27、支付宝账户（16 只、约 161 万）**

## 1. 基准数字

| 项目 | 数值 |
|------|------|
| 5/26 入账总资产 | ¥1,611,000 |
| 5/27 实时收益（header RT1） | ~¥19,133（含 5/26 美股正盘 + 5/27 亚太；**不含** 5/27 美股盘前） |
| 5/27 预估资产（盘前时段） | ¥1,611,000 + ¥19,133 ≈ **¥1,630,133** |

## 2. Canonical 公式

```
预估资产_t = 入账资产_{t−1} + 实时收益_t
```

| 符号 | 含义 |
|------|------|
| 入账资产\_{t−1} | 日 t 开始前 `Σ amount`（baseline `B[D]`） |
| 实时收益_t | row1 合计 RT1 |
| 入账资产_t | 日 t 结束后入账完成的 `Σ amount` → 成为 t+1 的 baseline |

**同一 Beijing 日 t 内 baseline 不变**；不在 US 正盘切换为 `amount + ep`；baseline 仅在日切滚动。

### Header 实现（scope）

```
预估资产 = 账户资产 + 实时收益合计
         = Σ amount + Σ estimateProfit
```

单基金列表行仍可用 `amount - settled + ep` 作 per-fund 展示 fallback。

## 3. 规则摘要

### 规则 1 — 账户资产

各基金 `amount` 之和，含已公布净值。对应 Hero「账户资产」主值。

### 规则 2 — 实时收益（row1 / header）

穿透估值 row1。盘前阶段 **不含** 美股盘前增量（row2）。

### 规则 3 — 净值入账

- A 股 / 黄金联接：通常当晚更新 **当天** 净值日
- QDII：可能更新 **上一 US 交易日** 净值日
- 入账更新：`amount`、当日收益、持有收益
- **预估资产不变**：仍 `B[D] + RT1`，不随 `amount` 增大而跳变

### 规则 4 — 21:30 美股正盘

- RT1 跟盘 live（regular + extended）
- EST = `B[D] + RT1`，baseline 不变

### 规则 5 — 多 Tab 互证

| Tab | 集合 | 互证 |
|-----|------|------|
| 支付宝 | accountId=alipay，不 merge | 基准 |
| 全部持仓 | merge by code | 同 code 跨账户一致 |
| 账户概况 | 各账户卡片 | Σ 各卡 RT1 = unmerged 全量 Σ |

### 规则 6 — 休市后冻结（EOD）

全日休市后 RT1 与 EST 整日冻结（EOD snap）。row2 在盘前/盘后阶段仍 live。

### 规则 7 — 盘前 16:00–21:30

| 更新 | 不更新 |
|------|--------|
| row2 盘前增量 | header RT1、EST、row1 各基金 |

### 规则 8 — 盘后 04:00–08:00

与盘前对称：row2 live；RT1/EST 以 **04:00 正盘收市 snap** 为准。

## 4. A 股基金 + 美股正盘

跟 A 股时段的基金（如 022364、001753、华安黄金 000216）：

- **每交易日 21:30 至次交易日 9:30 前** → 实时收益显示 **`—`**（含 21:30–04:00 美股正盘、04:00–09:30 盘前）
- **同日 15:00–21:30** → 可展示最后一次收盘估值 snapshot

## 5. 市场标签

顶栏状态条示例：`盘中 · 美股`、`盘前 · 美股`。  
**不**单独展示「黄金」；黄金联接按 A 股时段归类。

## 6. UI：实时收益双行

### 模式 A（无 extended）

竖排：金额 + 收益率

### 模式 B（盘前/盘后/夜盘）

```
+14,616.95  +0.89%        ← row1 RT1
+123.45  +0.01%  盘前      ← row2，tag 在行末
```

适用：Hero 顶栏、账户概况卡、列表 `.holding-col--split`。

row2 **不计入** row1；Hero 涨跌色仅看 row1。

## 7. 北京时间轴（5/27 示例）

| 时段 | RT1 | row2 | EST |
|------|-----|------|-----|
| 00:00–04:00 | US 尾段 live | — | live |
| 04:00–08:00 | snap | 盘后 live | snap |
| 08:00–16:00 | snap | 夜盘 live | snap |
| 16:00–21:30 | snap | 盘前 live | snap |
| 21:30–24:00 | live | 并入 RT1 | live |
| 晚间 NAV | live（若已过 21:30） | — | **不因 amount↑ 变** |

## 8. 验收场景

| # | 场景 | 断言 |
|---|------|------|
| 1 | 10:00 A 股盘中 | 模式 A，无 tag |
| 2 | 21:23 盘前 | 模式 B；row1 snap 不变，row2 live |
| 3 | 22:00 NAV 入账 | AMT/DAY 变；snap 阶段 RT1/EST 不变 |
| 4 | 22:00 美股正盘 | A 股基金 RT1 为 `—` |
| 5 | 5/27 盘前 EST | ≈ 1,630,133（1,611,000 + 19,133） |
| 6 | Header EST | ≈ 账户资产 + header RT1 |
